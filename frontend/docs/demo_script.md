# 2-minute demo
1. Launch `python main.py`; point out the 48×48 planetary atlas, unknown terrain, base, telemetry and mission panels.
2. Press **Tab** to scan a wider local area; coverage rises as new cells become known.
3. Press **Enter** to start autonomous target-seeking; show route/target overlays and live energy.
4. Use arrow keys or WASD to manually traverse adjacent cells. Invalid moves are rejected by the rover model.
5. Use **E** when standing on a discovered sample; cargo updates and the sample marker changes state.
6. Press **Space** to pause and **R** to reset to deterministic seed 17.
