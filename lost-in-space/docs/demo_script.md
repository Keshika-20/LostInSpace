# Demo Script (≈ 2–3 minutes)

1. **Launch** `python main.py`. Point out the dark planetary surface and the rover at base.
2. Press **START**. The explored region expands cell by cell — unknown terrain stays black.
3. Watch the cyan route appear as A* plans around rock formations.
4. When a golden crystal is discovered, the rover targets it, travels, and collects (carried data increases once).
5. Point at the dashboard: energy bar, coverage %, event log, metrics.
6. Optionally press **PAUSE**, then **RESET** to show deterministic rebuild.
7. Close with: “All decisions use only the known map — hidden obstacles and resources never leak into planning.”
